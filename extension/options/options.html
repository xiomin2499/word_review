WordReview 设置与手机绑定

在 Google 翻译网页自动采集生词，通过你的私有 GitHub Gist 同步到手机 PWA 闪卡 App。

第 1 步

绑定 GitHub 私有云端词本（Gist）

生词将保存在你自己的 Secret Gist（仅自己可见） 中，无需自建服务器。只需要勾选 gist 权限即可。

1. 去 GitHub 生成 Token（已自动预填 gist 权限）↗
第 2 步

手机端 PWA 扫码配对

把本项目的 docs/ 托管到 GitHub Pages（或任意 HTTPS 静态页面）后，填写你的 PWA 访问地址，手机扫码即可自动完成配置。

使用方式：用手机相机扫码并在浏览器打开，然后选择 「添加到主屏幕」 即可作为独立 App 使用。

注：Token 通过 URL #hash 传递，不会发送到任何服务端，手机端打开后会自动保存到本地并清空地址栏。
